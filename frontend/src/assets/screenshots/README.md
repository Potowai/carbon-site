# Screenshots for PWA Manifest

## Required Screenshots

### Desktop (wide form_factor)
- `desktop-1.png` - 1280x720 - Tableau de bord principal
- `desktop-2.png` - 1280x720 - Gestion des chantiers

### Mobile (narrow form_factor)
- `mobile-1.png` - 375x667 - Tableau de bord mobile
- `mobile-2.png` - 375x667 - Liste des chantiers

## How to create screenshots

1. Open the application at http://localhost:4200
2. Use browser dev tools to set viewport to required dimensions
3. Take screenshots of the main interfaces
4. Save as PNG with exact dimensions specified above
5. Place in this directory

## Notes
- Screenshots should show the actual application interface
- Include realistic data/content
- Ensure good lighting and clarity
- No dev tools or browser chrome visible
